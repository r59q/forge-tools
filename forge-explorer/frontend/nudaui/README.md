# Imported NudaUI source

The manifest records the official registry URLs, pinned revision, retrieval
metadata and SHA-256 checksums. `baseline/` is unchanged upstream comparison
material, intentionally duplicated from the initial working snippets and excluded
from jscpd. Maintained components and adapters remain subject to duplication checks.

See [the import/update workflow](../README.md#nudaui-source-workflow) and each
component's `DEVIATIONS.md`. Preserve [LICENSE](LICENSE) in redistributed source
and assets. Builds never contact upstream or replace local components.
